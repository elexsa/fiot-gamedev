# Кафедра ігрових систем — сайт ФІОТ КПІ

Офіційний сайт **кафедри ігрових систем** ФІОТ КПІ ім. Ігоря Сікорського. Освітня програма кафедри — **«Розробка комп'ютерних ігор»** (спеціальність 121 «Інженерія програмного забезпечення»).

> **⚠️ Статус: прототип.** Увесь текстовий контент — тимчасовий (Lorem Ipsum). Реальний контент деканат редагує через адмін-панель `/admin`.

## Стек технологій

- **Laravel 13** (PHP 8.3+) + **MySQL** — бекенд, БД
- **Filament 3** — адмін-панель деканату (`/admin`)
- **Vite 8** + **Tailwind CSS v4** — збірка та стилізація (тема `fiot-*`)
- **Alpine.js 3** — інтерактивність фронтенду
- **`<model-viewer>`** — 3D-модель на головній

## Сторінки

| Маршрут | Сторінка | Опис |
|---------|----------|------|
| `/` | Головна | Hero з 3D-моделлю, статистика, останні новини |
| `/about` | Про кафедру | Місія, цифри, викладацький склад, матеріальна база |
| `/disciplines` | Дисципліни | Інтерактивне «Дерево навичок» — з БД |
| `/admission` | Вступникам | Дорожня карта вступу + калькулятор НМТ |
| `/news` | Новини | Стрічка новин — з БД |
| `/news/{slug}` | Новина | Окрема стаття |
| `/partners` | Партнери | Картки компаній — з БД |
| `/contacts` | Контакти | Адреса, телефони, соцмережі |
| `/admin` | Адмінка (Filament) | CRUD для деканату |

## Швидкий старт

### Laravel Sail (Docker) — рекомендовано

```bash
docker compose up -d
sail composer install
sail php artisan migrate --seed   # створює таблиці + наповнює плейсхолдерами
sail npm run dev
```

### Локально (PHP + npm)

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install
npm run dev
```

## 🔐 Адмін-панель деканату (`/admin`)

Логін за замовчуванням (змініть через `ADMIN_EMAIL` / `ADMIN_PASSWORD` у `.env`):

- **Email:** `admin@gamedev.kpi.ua`
- **Пароль:** `password`

В адмінці деканат може:
- **Новини** — додавати/редагувати, RichEditor (форматування), завантаження обкладинки, публікація/чернетка
- **Освітні програми** — назва, спеціальність, ступінь, опис, зображення
- **Дисципліни** — назва, опис, категорія, рівень (Skill Tree), передумови (зв'язки дерева), завантаження силабуса (PDF), позначка «бос»
- **Викладачі** — ПІБ, посада, напрямки, фото, email
- **Партнери** — назва, сайт, логотип, опис
- **Налаштування сайту** — контакти (адреса, телефон, email, соцмережі) та статистика (числа на головній та сторінці «Про кафедру»)

Усі зміни миттєво відображаються на сайті.

## Контент

Весь контент (новини, дисципліни, викладачі, партнери, програми, контакти, статистика) зберігається в БД і редагується на `/admin`.

### Заміна зображень-заглушок

Секції з написами `[IMAGE: ...]` — місця під реальні фото (корпус 18, команда кафедри, комп'ютерні класи). Покладіть файли в `public/images/` та замініть блок-заглушку на `<img>`.

```

├── css/app.css              # Дизайн-система (тема fiot-*, кнопки, анімації)
```
