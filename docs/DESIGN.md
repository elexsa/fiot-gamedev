# Design System - Кафедра ігрових систем ФІОТ

> Це **живий документ-специфікація** дизайну сайту. Його читає кожен, хто додає сторінку чи компонент: розробник, дизайнер, представник деканату. Мета - простий, вишуканий та академічно-авторитетний стиль **без** «AI-слоп» вигляду.

## 1. Brand voice («голос»)

- Сайт **кафедри** - офіційний, чіткий, спокійно впевнений. Дозволена **одна (єдина) фірмова «гра»-деталь**; все інше - стримане і структуроване.
- Говоримо без гіпербол. Заголовки - **звичайним регістром** (не ВЕЛИКИМИ БУКВАМИ), стислі, на місці.

## 2. Палітра

Токени визначені в `resources/css/app.css` (`@theme`).

| Токен | Hex | Роль | Правило |
|-------|-----|------|--------|
| `fiot-black` | `#080809` | Основний фон | капвас, без декорацій |
| `fiot-dark` | `#14161C` | Фон карток/блоків | картки, секції |
| `fiot-primary` | `#4D11CC` | **Єдиний глобальний бренд-акцент** (фіолетовий) | кнопки, активний nav, акцент-бар |
| `fiot-accent` | `#12E631` | **Тільки інтеракція** (зелений) | hover, focus, активні стани + єдиний вертикальний акцент-бар заголовка |
| `fiot-gray` | `#9E9D9F` | Описовий текст | підзаголовки, secondary |
| `fiot-white` | `#F8F9FA` | Основний текст | заголовки, первинний текст |

**Ключові правила:**
- **Фіолетовий** - єдиний колір, що може з'являтись сам по собі на нейтральному фоні (кнопки, активний пункт меню, акцент-бар). Зелений сам по собі - ніколи.
- **Зелений** - **лише реакція**: навели, сфокусували, натиснули. (Виключення: одна тонка лінія-акцент біля заголовка - див. §4.) У стані спокою зелених бордерів, тіней, підсвіток немає.

## 3. Типографіка

- **Дисплей** (`Inter Tight`): лише `h1-h2` - великі, потужні, але **sentence-case**; щільний `leading`; `font-semibold`/`font-bold`; без `uppercase`; без `tracking-tighter` (максимум `tracking-tight`).
- **Тіло** (`Mulish`): `h3-h6` + body. Обмежена ширина абзаца (`max-w-prose`) - щоб не розтягувалось.

**Шкала розмірів** - лише реальні кроки (немає довільних `text-[10px]` у шаблонах):

| Роль | Клас |
|------|------|
| Підзаголовок / kicker | `text-xs` (12px) / `text-sm` (14px) |
| Body | `text-base` (16px) - `text-lg` (18px) |
| Лід / вступний абзац | `text-lg` - `text-xl` |
| Розділ H3 | `text-2xl` (24px) - `text-3xl` |
| Сторінка H2 | `text-3xl` - `text-4xl` |
| Головна H1 | `text-4xl` - `text-6xl` |

**Kicker / супровід:** нейтральний індекс-лейбл у **звичайному регістрі**, без mono, без uppercase. Приклад: `01 - Кафедра`, `Новини кафедри`.

## 4. Ритм і компонентна модель

### Page header / Section header
- Верхній **невеликий** підзаголовок (`kicker`) - `text-sm`, нейтральний `fiot-gray`, sentence case.
- Заголовок - `h1`/`h2`, sentence-case, на своєму рівні масштабу.
- **Єдина** гра-деталь: тонка **вертикальна зелена лінія-акцент** (`border-l-2 border-fiot-accent`, маленький лівий відступ) біля page/section заголовків - аналог бренд-бара Solidgate.

### Cards
- Плоскі, `bg-fiot-dark/40`, `border border-white/10`, radius `rounded-2xl`. Ховер: **колір бордера + легкий підйом** (`hover:border-fiot-accent/40 hover:-translate-y-1`). **Без** glow-тіней, без «скляних» піл-головок.

### Buttons
- Класи з `app.css`: `.btn .btn-primary|btn-outline|btn-secondary` + `btn-lg|md|sm`. Ховер/актив - зміна кольору чи бордера; фокус-ринг `ring-fiot-accent`; без світлових градієнтів чи glow.

### Badge / тег
- Тільки коли це **семантична мітка** (тег новини, категорія дисципліни). `text-xs`, sentence-case, `rounded-full px-2.5 py-1`, `border`, нейтральний фон - лише легкий акцент кольором. Жодних `font-mono`, `uppercase`, `text-[10px]` навіть на міткох.

### Stat
- Число - `text-4xl/5xl`, `font-bold`, `white`; лейбл - `text-sm`, `fiot-gray`, sentence case (без tiny mono uppercase.

### Icons
- Єдиний набір `x-ui.icon`; stroke-icons `(arrows, chevron, check), fill-icons `(telegram, discord, facebook)`. Одномірна `w-4 h-4`; колір - `currentColor`/`fiot-gray`.

## 5. Інтеракція

- **Hover**: зміна кольору тексту/бордера ( не прозорість-градієнтами.) transitions `duration-200`.
- **Focus**: focus ring `ring-fiot-accent` (з `ring-offset-fiot-black`).
- **Зелений** = сигнал інтеракції. Якщо елемент не інтерактивний - жодного зеленого поруч.

## 6. Специфічне: Skill Tree (єдина гра-карта)

- «Дерево навичок» - навмисна ігрова карта; їй дозволено лишатись графічною (лініі зв'язків, рівні>. Але лейбли - `text-xs`/`text-sm`, sentence-case; без довільних `text-[10px]`; без `[TAG]`-коментарів навколо.

## 7. Do-not list (анти-AI-слоп «контракт»)

Кодуємо бідь, що прибираємо, щоб стиль не «сповз» назад. При додаванні нового: **жодного** з цього:

1. Жодних `text-[10px]` / `text-[11px]` / довільних не-масштабних px - inline у view-шаблонах.
2. Жодного патерну `font-mono` + `uppercase` + `tracking-widest` разом (малий mono-капс «крик»).
3. Жодних фальшивих «термінальних» коментарів-підзаголовків: `[TAG] //`, `[PATCH_NOTES]` тощо.
4. Жодних зелених бордерів/тіней/glow у **стані спокою** (крім єдиної лініі-акцента заголовка>. Зелене - лише hover/focus/active.
5. Жодного `tracking-tighter` на body-тексті (лише на дуже великих заголовках h1 з дозволом.
6. Жодного «glassmorphism» баджей-декору: `bg-{color}/10` + `border-{color}/30` + `rounded-full` на не-мітках.
7. Жодних монo-«коду»-рядків у UI-контенті (фальшивий «developer» вигляд.

> **Підсумок** (одним реченням): строгобудівний, академічно-чистий капвас (нейтральні темні тони, sentence-case типографіка реального масштабу, фіолетовий як єдиний бренд), у якому живе **рівно одна** гра-деталь - тонка зелена лініія-акцент біля заголовків - і ще зелень **тільки як реакція** на наведення та фокус.
